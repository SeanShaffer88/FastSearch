# Security reporting

Use [private vulnerability reporting](https://github.com/SeanShaffer88/FastSearch/security/advisories/new) for suspected vulnerabilities. Include the release/commit, Windows build/architecture, impact and a small synthetic reproduction. Do not post secrets, private paths, payloads or dumps in public Issues. Ordinary bugs belong in Issues with redacted diagnostics.

Current development and the latest preview are reviewed on a best-effort basis; no response-time or backport guarantee is offered. Passing tests and checksums are not a security audit or publisher authentication.
